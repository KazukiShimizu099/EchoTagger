# Echo Tagger

**Echo Tagger** is a Minecraft Fabric mod distributed as precompiled JAR files for multiple Minecraft versions.

## Features

- Version-specific JAR builds
- Minecraft Fabric compatibility for listed versions
- Easy installation
- No source code included in this repository

## Supported Versions

| Minecraft Version |
|---|
| 1.21 |
| 1.21.1 – 1.21.11 |
| 26.1.2 |
| 26.2 |

Compatibility depends on the individual build. Use the JAR matching your Minecraft version.

## Installation

1. Install Minecraft with Fabric Loader for a supported version.
2. Download the matching Echo Tagger JAR from the `versions/` directory or GitHub Releases.
3. Place the JAR inside your Minecraft `mods` folder.
4. Launch Minecraft using the matching Fabric installation.
